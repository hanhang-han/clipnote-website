Mac怎么查看剪贴板历史记录？4种方法详解（2026）

发布于 2026年6月8日 · 阅读约 5 分钟

你有没有遇到过这样的场景：刚复制了一段重要的文字，结果不小心又复制了别的东西，之前的内容就被覆盖了？Mac 系统默认的剪贴板只能记住你最后一次复制的内容，一旦覆盖就无法找回。

这其实是很多 Mac 用户都会遇到的问题。好在，查看剪贴板历史记录并不是没有方法。本文将详细介绍 4 种查看 Mac 剪贴板历史的方法，从系统自带功能到第三方工具，总有一种适合你。

方法一：使用 Mac 自带的剪贴板查看器

macOS 其实内置了一个剪贴板查看功能，只是藏得比较深，很多用户并不知道。

打开方式

  1. 打开 Finder
  2. 在顶部菜单栏点击 编辑
  3. 选择 显示剪贴板

这时会弹出一个窗口，显示你当前剪贴板中的内容。

局限性

这个方法虽然不需要安装任何额外软件，但有一个致命的缺点：它只能显示你最后一次复制的内容。如果你想查看更早之前的复制记录，它是完全无能为力的。macOS 的系统剪贴板本质上是一个单次缓冲区，新内容会直接覆盖旧内容。

所以，如果你需要查看历史复制记录，这个方法并不够用。

方法二：使用终端命令 pbpaste

如果你是开发者或者习惯使用终端，macOS 自带了两个非常有用的命令行工具：pbcopy 和 pbpaste。

基本用法

在终端中输入以下命令，可以查看当前剪贴板内容：

pbpaste

如果你想持续监控剪贴板的变化，可以配合 watch 命令使用：

# 每2秒刷新一次剪贴板内容
watch -n 2 pbpaste

还可以将剪贴板内容保存到文件中：

# 将剪贴板内容保存到文件
pbpaste > clipboard_backup.txt

# 将剪贴板内容追加到文件
pbpaste >> clipboard_log.txt

局限性

  • 只能查看当前内容：和系统自带查看器一样，pbpaste 只能看到最后一次复制的内容
  • 不适合普通用户：需要熟悉终端操作
  • 无法保存历史：需要手动保存才能记录历史
  • 格式限制：对富文本、图片等格式的支持有限

如果你需要自动保存每次复制的内容，可以考虑写一个简单的脚本来实现日志记录，但这终究不是优雅的解决方案。

方法四：通过 Homebrew 安装

如果你已经安装了 Homebrew（macOS 的包管理器），安装剪贴板管理工具就非常简单了。以安装 CliperX 为例：

brew install --cask hanhang-han/tap/clipnote

如果你更偏好免费开源方案，也可以安装 Maccy：

brew install --cask maccy

安装后设置

  1. 首次打开应用时，macOS 可能会提示你授予辅助功能权限，这是正常的安全检查
  2. 在系统设置 → 隐私与安全性 → 辅助功能中，允许应用访问
  3. 根据你的使用习惯设置快捷键
  4. 建议将应用设置为「登录时自动启动」

常见问题 FAQ

Mac 系统剪贴板能保存多少条记录？

macOS 系统剪贴板默认只能保存1条记录，即你最后一次复制的内容。新的复制会直接覆盖旧内容。这也是为什么需要第三方工具来扩展这一功能。

剪贴板历史会占用很多内存吗？

不会。现代剪贴板管理工具经过优化，保存数百条文字记录通常只占用几十 MB 的内存和磁盘空间。CliperX、Maccy 等工具的内存占用通常在 20-50 MB 之间，对系统性能几乎没有影响。

剪贴板工具安全吗？会泄露隐私吗？

正规的剪贴板管理工具都会在本地存储数据，不会上传到云端（除非你主动开启了同步功能）。建议从官方渠道或 App Store 下载，避免使用来源不明的软件。如果你处理敏感信息（如密码），可以设置排除规则，让工具不记录特定应用的复制内容。

重启电脑后剪贴板历史会消失吗？

使用第三方剪贴板管理工具（如 CliperX、Maccy）保存的历史记录会持久化到磁盘，重启后依然保留。而系统自带的剪贴板内容在重启后会清空。

免费的剪贴板工具够用吗？

对于基本需求，免费工具如 Maccy 已经足够。但如果你需要更多高级功能（如 AI 辅助、智能分类、富文本预览等），付费工具能提供更好的体验。CliperX 以 ¥18 的买断价格提供了 AI 功能和灵动岛交互，性价比很高。
