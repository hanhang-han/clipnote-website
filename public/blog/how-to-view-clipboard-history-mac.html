你有没有遇到过这样的场景：刚复制了一段重要的文字，结果不小心又复制了别的东西，之前的内容就被覆盖了？能否找回历史取决于系统版本与是否已启用记录功能：macOS Tahoe 26 的聚焦已提供剪贴板历史，不能再笼统地说 Mac 只能保存一条记录。

方法一：使用系统自带功能（先看 macOS 版本）

macOS Tahoe 26：在聚焦中查看历史

按 Command–空格键打开聚焦，再按 Command–4 进入剪贴板。首次使用时按系统提示选择是否允许剪贴板搜索；然后搜索、复制或清除历史记录。剪贴板可能包含敏感内容，请谨慎启用。参见 Apple 官方操作说明与macOS Tahoe 26 功能说明。

旧系统或只需查看当前内容：访达剪贴板查看器

macOS 其实内置了一个剪贴板查看功能，只是藏得比较深，很多用户并不知道。

打开方式

  1. 打开 Finder
  2. 在顶部菜单栏点击 编辑
  3. 选择 显示剪贴板

这时会弹出一个窗口，显示你当前剪贴板中的内容。

局限性

这个方法虽然不需要安装任何额外软件，但有一个致命的缺点：它只能显示你最后一次复制的内容。如果你想查看更早之前的复制记录，它是完全无能为力的。这里说的是访达的当前内容查看器，不是 Tahoe 26 的聚焦历史功能。

所以，如果你需要查看历史复制记录，这个方法并不够用。

方法二：使用终端命令 pbpaste

如果你是开发者或者习惯使用终端，macOS 自带了两个非常有用的命令行工具：pbcopy 和 pbpaste。

基本用法

在终端中输入以下命令，可以查看当前剪贴板内容：

pbpaste

如果你想持续监控剪贴板的变化，可以配合另行安装的 watch 命令使用（macOS 默认不附带该命令）：

# 每2秒刷新一次剪贴板内容
watch -n 2 pbpaste

还可以将剪贴板内容保存到文件中：

# 将剪贴板内容保存到文件
pbpaste > clipboard_backup.txt

# 将剪贴板内容追加到文件
pbpaste >> clipboard_log.txt

局限性

  • 只能查看当前内容：和系统自带查看器一样，pbpaste 只能看到最后一次复制的内容
  • 不适合普通用户：需要熟悉终端操作
  • 无法保存历史：需要手动保存才能记录历史
  • 格式限制：对富文本、图片等格式的支持有限

如果你需要自动保存每次复制的内容，可以考虑写一个简单的脚本来实现日志记录，但这终究不是优雅的解决方案。

方法四：通过 Homebrew 安装

如果你已经安装了 Homebrew（macOS 的包管理器），安装剪贴板管理工具就非常简单了。以安装 CliperX 为例：

# 通过 Homebrew 安装 CliperX
brew install --cask hanhang-han/tap/clipnote

如果你更偏好免费开源方案，也可以安装 Maccy：

brew install --cask maccy

安装后设置

  1. 首次打开应用时，macOS 可能会提示你授予辅助功能权限，这是正常的安全检查
  2. 在系统设置 → 隐私与安全性 → 辅助功能中，允许应用访问
  3. 根据你的使用习惯设置快捷键
  4. 建议将应用设置为「登录时自动启动」

常见问题 FAQ

Mac 系统剪贴板能保存多少条记录？

访达查看器和 pbpaste 读取当前剪贴板；macOS Tahoe 26 的聚焦另有剪贴板历史。记录范围取决于系统版本和设置，不应把当前内容与历史混为一谈。

剪贴板历史会占用很多内存吗？

不会。现代剪贴板管理工具经过优化，保存数百条文字记录通常只占用几十 MB 的内存和磁盘空间。CliperX、Maccy 等工具的内存占用通常在 20-50 MB 之间，对系统性能几乎没有影响。

剪贴板工具安全吗？会泄露隐私吗？

CliperX 的剪贴板历史保存在本地；使用云端 AI 时，相关内容需要发送给 AI 服务处理。使用前请阅读隐私政策，不要将密码或其他敏感资料交给云端 AI。其他工具的数据处理方式应分别查看其官方隐私说明。

重启电脑后剪贴板历史会消失吗？

使用第三方剪贴板管理工具（如 CliperX、Maccy）保存的历史记录会持久化到磁盘，重启后依然保留。而系统自带的剪贴板内容在重启后会清空。
