常见问题 FAQ

买断制工具以后会变成订阅制吗？

这取决于开发者的商业策略。ClipNote 目前明确承诺买断制，未来不会转为订阅。建议选择信誉良好、承诺明确的产品。开源工具（如 Maccy）则不存在这个问题，因为即使开发者改变策略，社区也可以 fork 继续维护。

买断后还能获得更新吗？

通常可以。ClipNote 买断后仍可获得功能更新和 bug 修复。一些工具可能会区分「大版本更新」（可能需要重新购买）和「小版本更新」（免费），购买前建议确认具体的更新政策。

¥18 的工具质量靠谱吗？

价格不等于质量。ClipNote 是 macOS 原生应用，使用 SwiftUI 开发，代码质量和用户体验都不输 ¥299/年的产品。低价格更多是因为独立开发者的定价策略和较低的运营成本（无服务器、无云同步）。

如果不满意可以退款吗？

如果你通过 Mac App Store 购买，苹果提供 14 天无理由退款政策。如果通过官网直接购买，建议在购买前先使用免费试用版确认功能是否满足需求。ClipNote 提供免费下载体验，满意后再购买 Pro 版本。

如何通过 Homebrew 安装这些买断制工具？

ClipNote 支持 Homebrew 安装：brew install --cask hanhang-han/tap/clipnote。Maccy 同样支持：brew install --cask maccy。安装后首次打开可能需要授予辅助功能权限。
